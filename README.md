# hyeong-viewer

한글(.hwpx)로 된 법학 정리자료를 **죄 → 조문(①②③) → 구성요건 → 법리 → 세부·판례** 순서의 가로 마인드맵으로 바꿔, 단계별로 펼치고 가리며 외울 수 있게 해 주는 뷰어입니다.

- 원문 글자와 서식(밑줄·굵게·파란 메모·글자 테두리 두문자·각주·표)을 **한 글자도 바꾸지 않고** 구조만 나눕니다.
- 결과물은 인터넷 없이 열리는 **HTML 파일 하나**입니다.
- 이 레포에는 **원문이 들어 있지 않습니다**. 자료는 각자 비공개로 보관하세요. `sample/`은 자리표시용 예시입니다.

## 쓰는 법

```sh
# 1) hwpx → 트리 JSON (표준 라이브러리만 사용)
python3 -I convert/hwpx2tree.py 자료.hwpx -o tree.json --log build.log

# 2) 무손실 검사: 문단 순서·글자·서식·표 모양·각주가 원문과 모두 같은지 확인 (다르면 종료 코드 1)
python3 -I convert/verify_lossless.py 자료.hwpx tree.json

# 3) 단일 HTML로 묶기
python3 -I build.py --data tree.json --out 마인드맵.html --title "형법각칙 마인드맵"
python3 -I convert/verify_lossless.py 자료.hwpx 마인드맵.html   # 묶인 데이터도 다시 확인
```

`viewer/index.html`을 그대로 열면 tree.json을 끌어다 놓아 볼 수 있습니다. 파일은 브라우저 밖으로 나가지 않습니다.
`demo.html`은 `sample/sample.tree.json`으로 만든 예시입니다.

## 변환 규칙

문단 스타일 **이름**과 들여쓰기로 단계를 정합니다. ID는 하드코딩하지 않습니다.

| 원문 | 트리 |
|---|---|
| `개요 1·2` 중 `제N편` / `제N장` | 편 / 장 |
| `챕터 제목` `[…]` | 죄 (`[자주 반복되는 개념들]`, `[…총론]`은 개관) |
| 1열 표 안의 `…죄(제N조)는 ①…②… 성립한다` | 조문 박스. 요건 ①②③을 따로 표시 |
| `대표법리` | 구성요건 제목. 조문 요건과 맞으면 ①② 칩을 붙이고, 맞지 않으면 쟁점으로 둠 |
| 첫 문단이 `대표법리`인 1열 표 | 박스 하위요건 (직전 구성요건 아래) |
| `일반법리` / `중간분류` / `세부법리` / `참조` | 법리 / 중간 / 세부 / 참조·판례 |
| 다열 표 · 그 밖의 1열 표 | 비교표 · 사례 답안 박스 (그대로 보존) |

추가 정보(원문은 바꾸지 않음):

- `사안: 죄명 O/X` 형식에서 O/X 카드를 뽑습니다.
- 태그를 붙입니다: `‘X’란` 정의, `(홍)`·파란 글씨 채점 메모, `약술형`, `★`.
- 글자 테두리로 표시된 두문자를 따로 모읍니다.

## 뷰어

| 기능 | 내용 |
|---|---|
| 마인드맵 | 펼치기 단계 1(구성요건만) → 2(+법리) → 3(전부). 카드를 누르면 하위가 펼쳐집니다. |
| 가리기 | 셀로판지처럼 덮고 하나씩 눌러 떠올립니다. O/X 판례는 사안은 보이고 결론만 가립니다. |
| 빈칸 | 밑줄·굵은 핵심어와 조문 요건만 가립니다. 파란 메모는 가리지 않습니다. |
| 전체 지도 | 모든 죄의 구성요건 목차를 한눈에 봅니다. 가리기와 함께 쓸 수 있습니다. |
| 암기 카드 | 구성요건 목록 · 조문 요건 · 판례 O/X · 정의 · 약술형 · 채점 노트. 간격 반복(0/1/3/7/14/30일)으로 복습합니다. |
| 원문 | 원문 순서 그대로, 표와 각주까지 보여 줍니다. |

- 검색은 초성으로도 됩니다.
- 진도는 브라우저(localStorage)에만 저장됩니다. 정보 → 진도 내보내기로 백업하세요.
- 단축키는 `?`를 누르면 볼 수 있습니다.
